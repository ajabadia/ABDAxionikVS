Welcome
Hi and welcome to MODELmaker, the software that helps you create your own models for the <Neuron> synthesizer! We know you are burning to try out this fascinating new technology and you would like to start right away to convert your samples to find out how they work inside the synthesizer once they are "neuronalized".
But - as we are dealing with some computer network set ups that you may not be familiar with from your day to day work, we highly recommend to carefully read this manual first. Please follow the Network Hook Up instructions (see Chapter 7 on page 11) to make sure that your data transfers will be succesfull!

1 - Installation and Start
Move the distribution file to an appropriate location and unpack it. This creates the folder "NeuronMM_xxx" that contains the executable file (MODELmaker_xxx) plus everything else the application needs including a `Models' and `Sessions' folder.
Note: The `xxx' in the above names will be replaced by a MODELmaker version number.
Double-click on the executable file to start MODELmaker.
If you experience any problems starting the MODELmaker on MAC OS9, make sure the macintosh Runtime for Java MRJ 2.2.5 is installed on your Mac. This can be downloaded from www.apple.com.
On a Windows PC, the Java Runtime Environment (JRE v1.4.1 or later) must be installed. This is available on http://java.sun.com.

2 - Structure
Session: Contains key zones plus information about the <Neuron> model to be generated. A session can be saved and re-opened (see below). Please note that the sample files are referenced by location and name rather than contained in the session. If the samples are subsequently moved, you'll need to select the sample files again.
Key zones: Each key zone contains: low key, root key, high key, low velocity sample, high velocity sample, detune, volume and pan. The application ensures that zones cannot overlap and all keys (midi notes 0 to 127) are always covered, ie there are no gaps.
Model info: Model number as shown in <Neuron> (possible values from 0 to 511). Model name as shown in <Neuron> (max. 11 characters). Complexity of the model (1 to 10). Parameter set to determine the model parameters accessible via stick or menu within <Neuron>.

3 - Sample Format
Currently AIFF, mono, 44.1kHz, 16 bit.
4 - File Menu
Open Session: Open a previously saved session, ie load the zones, samples and model information for one model.
Save Session: Save the current zones, samples and model information for one model.
Import Samples: Import all samples in a folder collectively. Low key and root key information must be contained in each AIFF file. The zones will then be configured automatically. Optional information regarding velocity, detune and volume will also be extracted from each sample if available. Please note that you must select the folder rather than the samples contained within it. If there are two samples for the same zone, the sample with velocity < 64 will be designated as the low velocity sample and the sample with velocity >= 64 as the high velocity sample.

6


4 - File Menu (cont.)
Import by Name: Import all samples in a folder collectively. Low key and root key information must be contained in the name of each AIFF file. The zones will then be configured automatically. Optionally, a sample can be designated as a low or high velocity sample. Please note that you must select the folder rather than the samples contained within it.
The naming convention is as follows: name_rootkey_lowkey or name_rootkey_lowkey_v.
Example without velocity: Flute_72_68.aif.
To distinguish a low and high velocity sample, we might have Flute_72_68_v1.aif and Flute_72_68_v2.aif.
The name part (e.g. Flute) must not contain any underscore ('_') characters.
Any information within the AIFF files themselves is not used to configure the zones but will be used during the conversion process.

Process: Brings up a dialog box to enter the model information and invoke the conversion process.
Transfer Model: Brings up a dialog where you can choose a model folder to be transferred to the <Neuron> directly from MODELmaker. If you need to transfer more than one folder at a time you may prefer to use a 3rd party ftp client application (see chapter 7 on page 11 for more details) .
Once transferred, the models must be loaded into the <Neuron> database via the `load models' command in the load/dump menu. For a more detailed description on network settings and how to load models, please refer to the <Neuron> manual and chapter 7 on page 10 in this document.
Quit: Use this if you haven't eaten or slept for a while.

5 - Main Screen
"Process" button: Brings up a dialog box to enter the model information and invoke the conversion process.
Table of zones: Shows the details for all zones and allows the selection of one zone which is then displayed and edited below.
New Zone button: Press this to add a new zone by selecting a sample. The system puts the new zone in the most appropriate place by reading the information inside the sample (but not the file name). If it cannot decide where to place the zone, the user is prompted to click on the piano to select the low key which will be used to split the zone that the selected low key is in.
Remove Zone button: Press this to remove the currently selected zone (unless it's the only one).

Piano (zones): Graphical representation of the zones and their root keys. Click on a zone to highlight it in the table above and edit it in the zone detail section below.
Piano (keys): Use this to select a key when prompted to do so. The text below the piano indicates what the key is for (low, high, root or low key for a new zone) or is blank when the piano is "inactive".

8


Details for selected zone:
Hit either of the "Browse" buttons to select a low or high velocity sample. Each zone has to have a low velocity sample. If there is no (optional) high velocity sample, the low velocity sample will cover all velocity values. If a separate high velocity sample is specified, this will be used on <Neuron> whenever the velocity value goes above the velocity threshold as defined in the Resynator Menu (default = 63).
Hit the low, high or root key buttons (below or above the 3 note displays, not the displays themselves) to edit the corresponding value by hitting a key on the piano. Note that a root key can be outside its zone and thus any changes to it will not affect the zone boundaries. When moving the low or high key, the previous or next zone is adjusted accordingly, but will never be removed altogether (an appropriate error message is displayed if the user attempts to go too far).

Adjust the detune (-99 to +99 cent), volume (-32dB to +12dB) and pan (-50 to +50) values by using the sliders or enter values directly into the fields next to the sliders followed by Enter. Note that pan can also be set per Sound on <Neuron>. The pan setting here is for the model in a resynator.

6 - Process Dialog
Model number (No): Enter a number between 0 and 511 as used on <Neuron>. For example, model 310 will be stored in the folder NeuronMM_xxx/Models/310.model.
Model name (Name): Maximum 11 characters. Shown on <Neuron> once transferred.
Complexity: Choose a value between 1 and 10 (default = 8). The higher the complexity the more accurately the sample is modelled, but a lower complexity can be very effective, too, and helps keep the size of the model down.
Parameter Set: Choose a value between 0 and 9. The description of the parameter sets starts on page 13 of this document.
Progress text and bar: Shows which sample file out of how many is being converted and how far the conversion for this file has progressed.

Go button: Hit this to start the process of converting your samples into a <Neuron> model. All generated models will be stored on your computer's hard disk in the folder NeuronMM_xxx/Models/xxx.model. For details on how to transfer models to <Neuron>, see chapter 7 on page 11 of this document.
Cancel button: Hit this to cancel the conversion process. If you hit cancel while the conversion is in progress, it may take up to a few seconds to stop the process.

7 - Network Hook Up instructions
� To transfer new models (and any other data, like OS updates*, sounds, setups, etc.) to your <Neuron>, you need to connect your Mac/PC to <Neuron> via a USBEthernet Adapter (we recommend Hartmann UTEA 01, which is available through your Neuron dealer) or Belkin F5D5050. See our website www.hartmannmusic.com for information on other compatible adapters).
* OS updates may also be loaded into <Neuron> via MIDI.

If you are connecting your MAC/PC directly to the <Neuron> (via the USB Ethernet adapter), make sure to use a "crosslink" network cable (included with the Hartmann UTEA 01 adapter). If you are connecting through a network hub, make sure to use a standard network cable.

� Make sure, that your TCP/IP connection is set to "Ethernet" (on MAC) and "Manual".
� Your computer's IP address needs to be 192.168.1.x (x can be anything from 1 to 255 except 24, which is the <Neuron>). Set the subnet mask to 255.255.255.0.
There are two ways to transfer your generated models into <Neuron>:
A) Transfer single models using the "Transfer Model" function in the "File" menu of MODELmaker (see chapter 4 on page 7 of this document). This is the easiest way to load your own models into <Neuron>.

B)Use a third party FTP client application. For MAC we recommend the software "Transmit�" (www.panic.com) or "Fetch�" (www.fetchsoftworks.com). For PC we recommend "SmartFTP" (www.smartftp.com). In your ftp client application enter 192.168.1.24 for the server address, "neuron" for the user name and "neuron" again for the password. Make sure to set the transfer mode to "binary". Copy the separate model folders to "ToNeuron /Models". This is the best way to transfer complete model sets to <Neuron> and also from <Neuron> (i.e. to backup your <Neuron> database).
� After the transfer, run "Load Models" on the <Neuron> (Load/Dump menu, see <Neuron> User Manual for details). This may take a few minutes.
Note: To transfer sounds or setups to <Neuron> via the USB connector, also use a third party FTP client application as described above in option B)and the <Neuron> User Manual.

Scape

To optain straight sound manipulation, MODELmaker offers different parameter sets to process models from samples. All internal <Neuron> models have been created using such special parameter sets. See the following list to find out, which parameter set offers which sound manipulations.
Set0 - Default Set
This is a "neutral" set suitable for application to all kinds of sounds. Initially it is the tonal equivalent of the source material, which you can then process to your heart's content.
Level 1: 1 Torsion 3 Neutral Bends the resonance and tension of the vibrating medium (for example, a string) to "metallize" the tone (adding a metallic edge) and generate crossmodulation.

Level 1: 2 - HiTurbul 4 LoTurbul Excites the entire model to generate cross-talk with the body and loosens the links within the model's structure to generate sympathetic, inharmonic vibration.
Level 2: 1 Warm 3 Cold Generates warmth by changing material properties. Vice versa, it makes fat tones sound sterile and cold.
Level 2: 2 Planar 4 Tubular The model representing the body is composed of simple modules (a tubular system). Each of these tubes has parameters that can be shaped geometrically. It can have corners or be flat or spherical. This parameter distorts the tubes along a plane, meaning that it flattens the tubes and creates parallel walls. This changes the overtone structure.
Level 3: 1 / 3 Influence (> Sphere L1!) Determines if the changes made at sphere level 1 affect solely the original model or also the simplified synthetic oscillation model. This means that changes are only audible if the sphere level 1 parameter Natural>Stringed is not equal to 0.

ParSet 6 - Woodwinds
Parameter set 6 is very well suited for woodwind instruments. You can also achieve interesting results with organs, solo synth sounds, and other lead instruments.
Level 1: 1 String 3 Air Determines if a vibrating column of air ("Air") or string vibration ("String") generates the sound. In the case of an air column, the sound is created by the resonance of a stochastic (turbulent) airflow. A deterministic string model is used for the string (in simplified terms, this means without a transversal link).

Level 1: 2 Metallic 4 Natural Generates the kind of inharmonic frequencies produced by vibrating metal.
Level 2: 1 Synthetc 3 Natural A simplified static model is used here; the generator's oscillation is also simplified. The result is a static, periodic sound that is best described as "smooth."
Level 2: 2 Warm 4 Cold Determines the tolerance of the main oscillation modes. This adds warmth and variation to the signal, or subtracts these properties from it.
Level 3: 1 ToneHigh 3 Tone Low Determines the weighting of body resonance. This parameter affects the formants in the sound.
Level 3: 2 / 4 ToneIntn (Tone Intensity) Determines the amount of main resonance boost.

Set8 - Loop Factory
Parameter set 8 works best with loops, phrases, and similarly complex patterns. This set enables time stretching and pitch shifting in real-time.
Level 1: 1 / 3 SpdConst (Speed Constantity) Determines the speed of the rendered sound as a function of the keyboard, i.e. key tracking. At a value of 127, speed remains constant over the entire key range.

Level 1: 2 / 4 PitchVar (Pitch Variability) Determines the pitch of the rendered sound as a function of the keyboard. At a value of 0, the pitch remains constant over the entire keyboard.
Level 2: 1 / 3 Pitch Determines pitch without changing speed.
Level 2: 2 / 4 Speed Changes speed without changing pitch.
Level 3: 1 / 3 Coherent Simplifies the rendered model by imposing polymorphous restrictions. This transforms a complex mix of sounds into a few coherent signal sources.
Level 3: 2 / 4 OrangeNs (Orange Noise) Processes the signal via a complex resonator that lets only frequencies within the note scale pass, dampening all others. The basic pitch of the note scale is derived from the device's Master Tuning setting. It allows all frequencies to pass when you select the "WhiteNs" option.

Set9 - Multipurpose
Parameter set 9 is a generic set used for recording single-note instrument tracks. It is not suitable for complex phrases or loops. Though the model lets you shape the size and composition of the body precisely, you cannot alter the underlying sound generation process.

Level 1: 1 CrpSmall 3 CrpLarge (Corpus Small / Corpus Large)
Scales the size of the body and thus the pitch of its intrinsic resonance frequencies. You can create interesting effects by modulating this parameter on the fly, for example, via LFO or envelope.

Level 3: 1 / 3 CorpOpen (Corpus Opening) 2 / 4 Reflection Defines the body's reflectivity. High values yield an open sound; low values allow only a few high frequencies to pass out of the body.
